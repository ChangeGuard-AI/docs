# What is ChangeGuard?

ChangeGuard scores every Kubernetes deploy **0–100, before it lands**.

The **Change Safety Confidence (CSC) score** is deterministic and explainable — one number computed from four kinds of evidence already in your cluster:

- **Policy** — CIS benchmarks (KubeBench), your custom rules, deprecated APIs (Pluto)
- **Runtime** — Falco events, crash loops, OOMKills, restart storms
- **History** — how deploys like this one actually went in this cluster
- **Health** — node pressure, resource saturation, pending pods

Wire the score into CI and every deploy gets a verdict: ship, or hold with the evidence cited.

## How It Works

<Frame caption="ChangeGuard runs a lightweight, read-only agent inside your cluster that connects outbound over TLS — there is never any inbound access to your infrastructure.">
  ![ChangeGuard architecture: a read-only agent and scanners in your Kubernetes cluster connect outbound over TLS to the ChangeGuard platform on AWS, which scores posture and serves your dashboard.](https://install.changeguard.ai/assets/architecture.svg)
</Frame>

<Steps>
  <Step title="Install the operator">
    One command deploys the ChangeGuard operator. It manages the data collector, security scanners, and runtime detection from a single ChangeGuardAgent custom resource.
  </Step>
  <Step title="Evidence collects automatically">
    The collector pushes cluster snapshots every 10 seconds. KubeBench runs CIS benchmarks every 6 hours, Grype scans images every 4 hours and on every new deploy, Falco watches syscalls on every node in real time.
  </Step>
  <Step title="Every deploy gets a verdict">
    Watch scores at [app.changeguard.ai](https://app.changeguard.ai), then wire the [validate endpoint](/api-reference/validate) into CI so risky deploys are held before they land.
  </Step>
</Steps>

## Quick Install

```bash
curl -sL https://install.changeguard.ai | \
  CG_API_KEY=YOUR_API_KEY CG_CLUSTER_NAME=production sh
```

Your dashboard populates within 60 seconds. Full scan evidence appears within the first scan cycle.
