---

The Resource Graph provides a visual topology of your cluster showing relationships between namespaces, deployments, pods, services, and nodes.

## What It Shows

- Namespace hierarchy with resource counts
- Workload relationships (deployments → replicasets → pods)
- Service mesh (services → endpoints → pods)
- Storage (PVCs → PVs → storage classes)
- Node distribution (pod placement across nodes)

Use the search bar to filter by resource type or name. Click any node to see its details and related resources.
