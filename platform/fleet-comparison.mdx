---
title: "Fleet Comparison"
description: "Compare security posture and metrics across clusters"
---

Fleet Comparison provides a side-by-side view of all connected clusters, highlighting configuration drift and score differences.

## Metrics

| Metric | Description |
| --- | --- |
| CSC Score | Deployment safety score |
| CVE Count | Open vulnerabilities by severity |
| CIS Pass Rate | KubeBench pass percentage |
| Falco Alerts | Runtime alerts in last 24h |
| ArgoCD Sync | Synced vs. out-of-sync apps |
| Network Policies | Coverage percentage |
| RBAC Findings | Identity risk count |

## Cross-Cluster Intelligence

- Shared image vulnerabilities across clusters
- Configuration drift between identical environments
- Correlated restart storms
- Image version sprawl
