<Info>
  **An optional Edge setting, scoped to scan analysis.** These `ai` settings live on the `ChangeGuardAgent` resource of the optional Edge collector and route only the collector's on-cluster explanations of scanner findings. They do not change where ChangeGuard's judgment or its Engineering Advisor run (the control plane, on Amazon Bedrock), and they are not required for anything. Self-hosted inference for judgment and reasoning is roadmap — see [Known limitations and roadmap](/concepts/limitations-and-roadmap).
</Info>

## Cloud Mode

### Step 1: Get an API Key

Sign up at [build.nvidia.com](https://build.nvidia.com) and generate an API key.

### Step 2: Create a Secret

```bash
kubectl create secret generic nvidia-api-key \
  --from-literal=api-key=nvapi-YOUR_KEY \
  -n changeguard-system
```

### Step 3: Configure the CRD

```yaml
spec:
  ai:
    mode: cloud
    apiKeySecretRef:
      name: nvidia-api-key
```

## On-Cluster Mode

For air-gapped environments or data sovereignty:

```yaml
spec:
  ai:
    mode: oncluster
    onCluster:
      image: "nvcr.io/nim/meta/llama-3.1-70b-instruct:latest"
      gpuRequest: "1"
      memoryLimit: "80Gi"
```

Requires 1\+ NVIDIA GPU (A100/H100/L40S recommended) with 80GB\+ GPU memory.

## AWS Mode

```yaml
spec:
  ai:
    mode: aws
    endpoint: https://your-nim-endpoint.sagemaker.aws
```
